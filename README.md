# تحديث تصميم بوسترات CBP-BC وCBP-BE

تم تحديث البوسترين داخل المتجر ليكونا بنفس الأسلوب البصري لبوستر CBP-CS:
- خلفية تركواز/أزرق
- نقاط زخرفية أعلى اليسار
- شعار محترف في الأعلى
- اسم الشهادة بالعربي
- الكود كبير في المنتصف
- خصم 50%
- السعر 500 ر.س
- اختبار شهادة احترافية فقط
- بدون أي عبارة «مدعومة من هدف» أو «مستردة من هدف»
