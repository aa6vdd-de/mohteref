# تحديث الكتب الجامعية

تم تنفيذ التعديلات المطلوبة:
- تغيير مسمى «كتب السنة التحضيرية» إلى «الكتب الجامعية» في القائمة والعناوين العامة.
- تحديث مقدمة صفحة الكتب بالنص المطلوب.
- توضيح أن الكتب متاحة فقط لطلبة جامعة تبوك.
- إضافة أماكن الاستلام للفرع الرئيسي وفروع الكليات.
- الحفاظ على أسماء المقررات نفسها كما هي لأنها تشير إلى مقررات السنة التحضيرية.
