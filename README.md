# تحسين انتقال العروض

تم تحسين انتقال العرض في واجهة المتجر بحيث:
- يختفي العرض الحالي بنعومة قبل ظهور التالي.
- البوستر يتحرك حركة خفيفة بدل التغيير المفاجئ.
- النص والسعر يدخلان بحركة مستقلة وهادئة.
- تم تحميل صور العروض مسبقاً لتفادي الوميض.
- أصبحت مدة بقاء كل عرض 5.2 ثانية.
- يتوقف التبديل مؤقتاً عند مرور الماوس فوق العرض، ثم يكمل تلقائياً.
