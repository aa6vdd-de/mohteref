# تحديث سلايدر الصفحة الرئيسية بالعروض

تم الإبقاء على سلايدر الصفحة الرئيسية الحالي كما هو، وإضافة 3 شرائح عروض جديدة:
1. عرض CBP-AI — خصم 27% — 2,299 ر.س بدل 3,165 ر.س.
2. عرض Power BI — خصم 27% — 2,299 ر.س بدل 3,165 ر.س.
3. عروض اختبارات CBP-LS / CBP-CS / CBP-S — 899 ر.س لكل اختبار بدل 1,010 ر.س.

الشرائح الجديدة تستخدم صور العروض الموجودة داخل مجلد `assets`، وأزرارها تنقل المستخدم إلى صفحة `store.html`.

تم تقليل مدة تبديل السلايدر قليلًا لتناسب زيادة عدد الشرائح.
