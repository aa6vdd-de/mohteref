# إصلاح مباشر لقائمة الجوال

تم إصلاح زر القائمة ☰ في:
- صفحة الكتب الجامعية
- صفحة شركاؤنا

التعديل الأساسي:
- زر القائمة أصبح يفتح/يغلق القائمة مباشرة من `onclick` داخل الزر نفسه.
- لم يعد يعتمد على بقية JavaScript في الصفحة.
- أزيلت مستمعات النقر القديمة لتجنب تنفيذ التبديل مرتين.
- تم رفع `z-index` وتفعيل `pointer-events` لضمان استجابة اللمس في Safari/iPhone.
