# تحديث هيكل الصفحة الرئيسية

تم تنفيذ المطلوب بدون تغيير محتوى أو تصميم الصفحة الرئيسية الحالي:

- حذف صفحة `latest.html` المستقلة لأن قسم **أحدث الشهادات** موجود أصلًا داخل الرئيسية.
- نقل قسم **جميع الشهادات** داخل الصفحة الرئيسية ووضعه مباشرة قبل قسم **عروض خاصة من مركز محترف**.
- تغيير اسم رابط الصفحة الرئيسية إلى **الشهادات الاحترافية والبرامج المهنية**.
- إبقاء قسم أحدث الشهادات داخل الرئيسية كما هو.
- رابط **جميع الشهادات** في القائمة أصبح ينقل مباشرة إلى قسمه داخل الرئيسية.
- أبقينا `catalog.html` فقط كتحويل تلقائي للرابط القديم حتى لا تنكسر الروابط المحفوظة.
