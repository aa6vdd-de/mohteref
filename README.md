# النسخة المصححة — التصميم المتفق عليه

هذه النسخة تحافظ على التصميم النظيف المتفق عليه في صفحة **المتجر والعروض**:
- لا توجد أسهم.
- لا توجد نقاط.
- لا يوجد عداد 1/5.
- بطاقة العرض تتغير تلقائياً بين العروض فقط.
- كتب السنة التحضيرية غير موجودة في صفحة المتجر.

وفي نفس الوقت تم الإبقاء على **العروض المضافة داخل سلايدر الصفحة الرئيسية** كما طلبت.
