# إصلاح نهائي لظهور بطاقات الشهادات

تم إصلاح خطأ JavaScript الذي كان يمنع بطاقات الشهادات من الظهور.

التعديلات:
- استرجاع بطاقات «أحدث البرامج الاحترافية» و«جميع الشهادات» بشكلها السابق العامل.
- عدم إظهار شريط دعم هدف الأخضر داخل بطاقات الصفحة الرئيسية.
- حذف تنبيه هدف الطويل من الصفحة الرئيسية.
- في صفحة المتجر: إظهار «✓ مدعومة من هدف» فقط بدون مبلغ داخل خانة الدعم.
