# مركز محترف — استرجاع محتوى الرئيسية + حذف تنبيه هدف

تم تنفيذ المطلوب كالتالي:
1) **استرجاع الصفحة الرئيسية** إلى النسخة التي كان يظهر فيها المحتوى بشكل طبيعي (بدون الفراغات التي ظهرت لاحقًا).
2) **حذف نص التنبيه**:
   «مبالغ «هدف» المعروضة تمثل الحد الأعلى للتعويض عن تكاليف الحصول على الشهادة وفق شروط وأهلية برنامج الشهادات المهنية الاحترافية، وليست سعر بيع الشهادة.»
3) في **صفحة المتجر والعروض فقط**:
   - تم الاكتفاء بعبارة: **✓ مدعومة من هدف**
   - بدون عرض مبلغ التعويض داخل هذه الخانة.
