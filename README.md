# تحديث صفحة العروض

تم تعديل صفحة العروض بحيث:
- إزالة الشكل النصي القديم (LS / CS / S / AI / BI) من بطاقات العروض.
- استخدام **ملصق/شعار** لكل عرض في أعلى البطاقة.
- إضافة **شعار صغير** داخل كل بطاقة عرض.
- تطبيق التعديل على:
  - `store.html`
  - قسم العروض داخل `index.html`

وتوجد الصور داخل مجلد `assets`.
