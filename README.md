# نسخة مركز محترف متعددة الصفحات

تم تحويل عناصر القائمة العلوية من روابط تنزل لنفس الصفحة إلى صفحات مستقلة:

- `index.html` — الرئيسية
- `latest.html` — أحدث الشهادات
- `store.html` — المتجر والعروض
- `colleges.html` — الكليات
- `catalog.html` — جميع الشهادات
- `about.html` — عن محترف

ارفع **كل الملفات معًا في نفس المجلد** على GitHub Pages.

ملاحظة: أبقيت البنية والسكربت الأصليين داخل الصفحات حتى لا تتعطل وظائف البحث والفلترة والنوافذ المنبثقة. كل صفحة تعرض القسم الخاص بها فقط.
