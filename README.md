# تحديث الصفحة الرئيسية — دمج الدليل المهني

تم تنفيذ ملاحظات Canva الأخيرة:
- أصبحت الصفحة الرئيسية هي صفحة الدليل الشامل للشهادات الاحترافية والبرامج المهنية.
- تم تغيير اسم الصفحة الرئيسية إلى: **الشهادات الاحترافية والبرامج المهنية**.
- تم دمج قسم **أحدث الشهادات والبرامج المهنية** داخل الرئيسية.
- تم دمج قسم **الشهادات والبرامج المناسبة حسب الكلية** داخل الرئيسية.
- تم حذف الصفحتين المستقلتين `latest.html` و`colleges.html` بعد نقل محتواهما المهم.
- تم تحويل أي روابط قديمة لهما إلى الأقسام المقابلة داخل الصفحة الرئيسية.
- `catalog.html` أصبح تحويلًا تلقائيًا إلى قسم الدليل داخل الرئيسية للحفاظ على الروابط القديمة.
