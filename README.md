# إضافة صفحة شركاؤنا

تمت إضافة صفحة `partners.html` بعنوان **شركاؤنا** مع شريط شعارات متحرك وبطاقات تعريفية للشركاء.

الشركاء المضافون:
- جامعة الحدود الشمالية
- جامعة تبوك
- مؤسسة عبدالله الراجحي الخيرية
- شركة قيمة (شعار نصي مؤقت لعدم توفر صورة شعار في الملفات المرسلة)
- IBTA
- تمارا

تمت إضافة رابط **شركاؤنا** إلى القائمة العلوية في جميع الصفحات.
