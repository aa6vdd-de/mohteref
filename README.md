# مركز محترف — حركة ظهور سلسة عند التمرير

تمت إضافة حركة خفيفة وناعمة عند النزول في صفحات الموقع:
- العناوين تظهر تدريجيًا من الأسفل.
- البطاقات تظهر بتتابع بسيط.
- الحركة تعمل مرة واحدة فقط لكل عنصر.
- تم احترام إعداد prefers-reduced-motion.
- تم الحفاظ على تصميم الموقع الحالي بدون تغيير الهوية أو المحتوى.
