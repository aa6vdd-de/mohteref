# مركز محترف — المتجر بدون كتب السنة التحضيرية

تم حذف كتب السنة التحضيرية بالكامل من صفحة `store.html` (المتجر والعروض)، بما في ذلك:
- عنوان قسم الكتب
- بطاقات الكتب الثلاثة
- الملاحظة أسفل الكتب
- زر «كتب جامعة تبوك» داخل واجهة المتجر
- الإشارة إلى الكتب في وصف واجهة المتجر

تظل صفحة `books.html` مستقلة للكتب، وتظل الصفحة الرئيسية كما هي.
