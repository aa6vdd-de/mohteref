# تحديثات Canva المجمعة

تم تطبيق الملاحظات الواردة في الصور:
- الكتب الجامعية: إخفاء شعار جامعة تبوك من البوسترات بصريًا، إضافة حالة توفر لكل كتاب، وإضافة تنبيه أن التقسيط متاح عبر تمارا فقط.
- الكليات: تغيير العنوان إلى المسارات المهنية ذات العلاقة بالشهادات الاحترافية والأنسب حسب التخصص.
- عن محترف: إضافة النص التعريفي المطول بالمركز.
- الرئيسية: إضافة قسم «ماهي الشهادة الاحترافية؟» بالتعريف والمتطلبات والهدف وآلية الحصول.
- الفوتر: حذف عمود المجالات، تحديث وصف المنصة، تحديث موقع المركز إلى عمادة شؤون الطلاب مبنى 38 الدور الأول، وإضافة روابط واتساب وX وإنستغرام.
