# مركز محترف — نسخة الصفحات المستقلة مع رئيسية شاملة

تم تعديل الصفحة الرئيسية بحيث تعرض **كل محتوى الموقع في صفحة واحدة**:
- البانر الرئيسي
- الإحصائيات
- أحدث الشهادات
- المتجر والعروض
- كتب السنة التحضيرية
- الكليات
- جميع الشهادات
- لماذا محترف / الشركاء

وفي نفس الوقت، عناصر القائمة العلوية تفتح صفحات مستقلة:
- `index.html` — الرئيسية الشاملة
- `latest.html` — أحدث الشهادات
- `store.html` — المتجر والعروض
- `books.html` — كتب السنة التحضيرية
- `colleges.html` — الكليات
- `catalog.html` — جميع الشهادات
- `about.html` — عن محترف

ارفع جميع الملفات معًا في نفس المجلد على GitHub Pages.
