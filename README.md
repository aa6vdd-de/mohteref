# مركز محترف — إعادة تصميم بطاقات الشهادات

تم إعادة تصميم بطاقات الشهادات في الصفحة الرئيسية لتصبح أقرب لأسلوب بطاقات المتجر التي تم طلبها:
- جزء علوي Poster كبير بتدرج لوني وهوية محترف
- إظهار الرمز بشكل كبير (مثل CBP-LS)
- شارة «مستردة من هدف» داخل الـPoster للشهادات المدعومة
- جزء سفلي مرتب يحتوي:
  - الرمز
  - وسوم (اختبار شهادة / احترافية)
  - العنوان الكامل
  - السعر المعتمد من هدف بأسلوب أوضح
  - صندوق دعم هدف بتنسيق أنيق
  - التخصصات المناسبة
  - أزرار التسجيل وعرض التفاصيل
