# النسخة المعتمدة - التصميم المتفق عليه

تم تثبيت تصميم العرض المتفق عليه داخل صفحة المتجر وقسم المتجر في الرئيسية:
- بدون أسهم.
- بدون نقاط.
- بدون عداد 1/5.
- العرض يتبدل تلقائيًا بين جميع العروض.
- الصورة والسعر والنص داخل بطاقة متناسقة مع هوية الصفحة.
- صفحة المتجر لا تحتوي على كتب السنة التحضيرية.
- الصفحة الرئيسية تحتفظ بشرائح العروض الجديدة في السلايدر الرئيسي.
