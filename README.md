# النسخة المصححة — نقل جميع الشهادات إلى الرئيسية

تم تنفيذ المطلوب على التصميم السابق بدون تغيير محتوى أو شكل الصفحة الرئيسية:

1. قسم **أحدث الشهادات** يبقى داخل الصفحة الرئيسية كما هو.
2. تم حذف ملف الصفحة المستقلة `latest.html` فقط.
3. قسم **جميع الشهادات** تم نقله داخل `index.html` ليظهر مباشرة **قبل قسم عروض خاصة من مركز محترف**.
4. اسم رابط الصفحة الرئيسية في القائمة أصبح **الشهادات الاحترافية والبرامج المهنية**.
5. رابط **جميع الشهادات** في القائمة ينقل إلى `index.html#catalog`.
6. باقي الصفحات والتصميم لم يتم حذفها أو إعادة تصميمها.
7. تم تضمين مجلد `assets` في الحزمة.
