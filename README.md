# تحديث العروض الرئيسية التفاعلية

تم تحويل البطاقة الكبيرة في قسم **المتجر والعروض** إلى بطاقة **تفاعلية/سلايدر** تعرض جميع العروض الموجودة تلقائيًا:
- CBP-LS
- CBP-CS
- CBP-S
- CBP-AI
- POWER BI

التحديث موجود في:
- `store.html`
- قسم المتجر داخل `index.html`

ويمكن التنقل بين العروض من خلال الأسهم أو النقاط السفلية، مع تبديل تلقائي كل عدة ثوانٍ.
